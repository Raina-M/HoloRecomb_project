# Marey maps (Fig. 3c, Supplementary Fig. 9)

`plot_genetic_map_*.R` plot cumulative genetic position against physical position for the species combinations in their names.
Inputs: `merged_linkage_*.txt` (included). The scripts also read per-species tables `linkage_info_for_plot_*.txt` for the
side panels, which are derived from the single-gamete genetic maps (Supplementary Dataset 3) and are not included here.
