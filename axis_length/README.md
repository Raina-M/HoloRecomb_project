# ZYP1 axis length (Fig. 4a, b; submitted version)

- `per_nucleus/compaction_rate.R`: total ZYP1 axis length per pachytene nucleus divided by haploid genome size, against mean
  chromosome size (`axis_lengths.txt`, `chrs_lengths.txt`).
- `per_chromosome/axis_length_vs_CO_rate.R`: proportional axis length per chromosome against double-CO frequency.

The revised Fig. 4a, b, including the least-squares fit of species medians and the linear mixed model for panel b, is built by
`HoloRECOMB_HiC/analysis/08_fig4.py` from the same measurements.
