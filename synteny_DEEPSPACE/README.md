# DEEPSPACE synteny

`DEEPSPACE_run.R` (J. T. Lovell) runs DEEPSPACE synteny and karyotype reconstruction for the 20 Rhynchospora genomes with CO
landscapes as tracks (Fig. 1a, Extended Data Fig. 1). Input paths at the top of the script point to the author's local copies
of the assemblies, annotations and recombination landscapes and must be set before running; MCScanX is required.
