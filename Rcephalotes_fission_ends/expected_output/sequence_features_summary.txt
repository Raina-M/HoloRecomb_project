Individual observations
- 45S rDNA: the only 45S rDNA array in the assembly (51 copies of an 18S probe; GC ~61%) occupies the last ~420 kb of chr3 (35.53-35.95 Mb), a fission-derived end. The assembly ends inside the array, without a telomere.
- Ends without an assembled terminal telomeric array: chr1 end (terminal rearrangement), chr3 end (fission-derived, rDNA), chr7 start (conserved); chr6 start (fission-derived) carries a degenerate C-rich telomere-like array (CCCCCCA/CCCTAA variants, ~1.7 kb of motif in the terminal 20 kb).
- Assembled telomeric arrays are 1.6-3.9 kb at all other ends; HiFi assemblies truncate telomeres, so these values do not measure telomere length.
